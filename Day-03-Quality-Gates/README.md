# Day 03 – Quality Gates & Quality Profiles

## Goal
Understand how organizations decide whether code is good enough to proceed.

## Topics
- Quality Profile: defines which rules are checked
- Quality Gate: defines whether the project passes or fails

## Hands-on
- Created/configured a Quality Gate (Coverage ≥ 80%, Duplications < 3%, Bugs = 0, Vulnerabilities = 0)
- Introduced intentionally bad code (hardcoded password, unused variable, dead code) and analyzed results
- Compared before/after fixing the issues
